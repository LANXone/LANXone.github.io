OpenGL环境配置

OpenGL 入门：从零搭建 GLFW 开发环境（Windows + MinGW）

适合完全不懂编译链的新手，手把手教你把 GLFW 源码变成能跑的 exe。

前言

刚入坑 OpenGL 的时候，网上的教程要么跳过环境搭建”假设你已经配好了”，要么三言两语”装个 GLFW 就行”。但实际上：

  • 你下载的 GLFW 源码 .c 文件，电脑根本不认识
  • 直接 #include <GLFW/glfw3.h> 会报”找不到头文件”
  • 就算头文件能找到，链接阶段还会报一堆 undefined reference

这篇文章记录我从零到跑通第一个 GLFW 窗口的完整过程，每一步都解释”为什么要这么干”。

一、准备工作：你需要这 3 样东西

东西 说明 获取方式
MinGW-w64 GCC/G++ 编译器，把 C++ 代码变成 exe 搜 w64devkit 下载解压，免安装
CMake 帮你编译 GLFW 源码的”自动化脚本生成器” w64devkit 里自带，或 cmake.org 单独下
GLFW 源码 glfw.org 下载 Source 包（不是 binary 包） 解压到你的项目目录

八、常见问题

Q: 为什么不用 CMake 直接编译我的项目？

可以，但 CMake 对新手来说更难学。直接用 g++ 命令能让你彻底搞懂编译器需要哪些信息。等项目变大了再切 CMake 也不迟。

Q: GLFW 编译时报找不到编译器？

CMake 需要知道 gcc/g++ 在哪。确认 w64devkit/bin/ 在 PATH 里，或者在 cmake 命令前加：

Q: 编译运行后窗口是黑屏？

正常！我们的代码只做了 glClear(GL_COLOR_BUFFER_BIT) 用默认黑色清屏。等你学到着色器就能画彩色东西了。

Q: GLFW 和 OpenGL 是什么关系？

  • OpenGL：图形 API（一套画东西的函数规范），显卡驱动实现
  • GLFW：窗口 + 输入管理库（创建窗口、处理鼠标键盘、管理 OpenGL 上下文）
  • GLAD/GLEW：加载 OpenGL 函数指针（现代 OpenGL 3.3+ 核心模式需要）

简单说：OpenGL 负责”画”，GLFW 负责”给你一个能画的窗口”。
