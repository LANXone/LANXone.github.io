写在最前面：先记住三句话

1. 你现在最该做的事只有一件：买一块 STM32 开发板，今晚就下单。

不是因为它有多重要，而是因为它是一个能立刻开始的动作。职业规划最怕的就是"想了很多但什么都没做"。

2. 你最大的优势是地理和时机。

广东的嵌入式产业布局（深圳的芯片/方案公司、广州的工业和汽车、东莞的制造）是你择校时带来的红利。留在广东，就业机会比大多数省份多得多。 不要轻易去外地。

3. 这四年不是要"赢过谁"，是要"建成一套能变现的能力"。

不用焦虑对比同学。你只需要每年比现在强一点。大二会 STM32，大三有项目 + 实习，大四拿 offer —— 这就够了。

从数据里能读出的三个判断

判断一：这个专业在广工是优势专业，不是垫底专业。

排名进前 7 意味着课程体系、师资、认可度都不差。你不需要为了逃避专业而焦虑。 物联网工程是当前国家战略方向，不会过时。

判断二：地理优势极大。

63% 去广州、13% 去深圳 —— 而嵌入式/物联网的产业全在这里。这意味着你留在广东就有岗位，不用北上广深杭卷。区域选择本身就是一种竞争力。

判断三：起点薪资 6287 不高，但这正常。

广工不是华工/中山，0年经验 6K 左右是合理价位。关键不是起点多高，是 5 年后能不能到 12477 甚至更高。

而这个数字取决于你选的赛道（见下一节）。

二、嵌入式行业全景：分赛道决定薪资

残酷的真相：同样叫"嵌入式工程师"，应届起薪差 3 倍

我在招聘数据里发现一个极其残酷的分层：

方向 应届起薪 3-5年 5年+ 核心溢价点 现状评价
传统单片机（消费电子） 6-9K 15-25K 30-40W 低成本方案、量产交付、兼容性 🔴 低端内卷严重
物联网网关 / 云边协同 8-12K 18-28K 20-30W MQTT、LoRa/NB-IoT、云平台对接 🟡 稳定但溢价有限
边缘 AI / 模型部署 12-18K 25-40K 50-100W TFLite/NCNN、模型量化、低功耗优化 🟢 复合技能溢价高 50%
嵌入式 Linux 驱动 18-25K 30-50K 60W+ 设备树、内核裁剪、车规/工业级 🟢 门槛高天花板高
车载电子（座舱/BMS/域控） 14-20K 25-40K 60-100W AUTOSAR、ISO26262 功能安全 🟢 几乎不裁员

注意第一行和最后一行的差距：应届起薪 6-9K vs 14-20K，差 3 倍。

行业里流传一句话叫"嵌入式分赛道，选错等于白干" —— 我在招聘数据里看到，有人做蓝牙耳机月薪 8K 还得天天加班，有人做工业控制 20K 起还能双休。

关键洞察：这个分层不由"你聪不聪明"决定，而由"你选的细分赛道"决定。 新人无法改变行业，只能选赛道。

行业四大风口（都在招嵌入式）

风口 具体机会 特点
1. 新能源汽车 BMS 电池管理、电机控制器、自动驾驶域控、智能座舱 车载电子成本占整车 40%+，车规岗薪资第一梯队，几乎不裁员
2. 端侧 AI 爆发 工业传感器、家用摄像头、智能穿戴、机器人本地 AI 推理 嵌入式 + 边缘 AI 复合技能溢价高 50%

4. 工业自动化 / 人形机器人 工厂工控、伺服电机、机械臂、家用机器人 越老越吃香，工作经验是护城河，避开 35岁危机

嵌入式的三个现实痛点（要知道，别幻想）

  1. 入门门槛比互联网高 —— 必须吃透 C/C++、操作系统、硬件时序、电路图、通信协议，前期学习周期长
  2. 低端岗位内卷严重 —— 只会基础单片机没高阶项目，只能混小家电行业
  3. 工作环境相对辛苦 —— 经常面对示波器、电路板、车间调试，比坐办公室写代码累

但也有对应优势：技术壁垒强，不容易被替代，裁员风险小。

三、我的方向建议

首选：嵌入式 Linux 驱动 / 边缘 AI

理由：

  1. 起薪最高（应届 18-25K），和传统单片机差 3 倍
  2. 技能可迁移 —— 学会了在任何芯片平台都能用，不像单片机那样绑死某个芯片
  3. 不担心 35 岁 —— 这是少数越老越值钱的领域，硬件调试经验需要长年累月实操沉淀
  4. 广东需求旺盛 —— 深圳一堆芯片公司、方案公司

风险： 学习曲线陡。需要先打好 C + 操作系统 + 驱动基础。

次选：车载电子

理由： 稳定性最好，几乎不裁员，5 年后 60-100W。

风险： 门槛稍高（AUTOSAR、ISO 26262 功能安全要求），岗位主要集中在深圳、上海。

避开：传统消费电子单片机

理由： 这是嵌入式里的"低端内卷"区。新人只能做重复性工作，成长空间小，天花板低。

备选：物联网网关 / 云边协同

理由： 和你专业最对口，MQTT/LoRa/NB-IoT + 云平台对接，技术栈广。

不足： 溢价有限（8-12K 起）。如果你想在这个方向做出差异，需要叠加边缘 AI 或 Linux 驱动技能。

决策建议

大一大二先不急着定死方向。 你现在只需要做一件事：

先把 STM32 学会，做到能独立完成项目。 有了这个基础，你在大二末、大三初就能真正判断自己对哪类技术感兴趣、擅长什么。

方向是在实践中试出来的，不是在大一就规划出来的。

四、当下（大二上）该做什么

这是本笔记最核心的部分。

时间分配的真相

按每周 20 小时课外时间算（学业之外能挤出的时间）：

投入方向 时长 占比 理由
STM32 + 嵌入式基础 8h 40% 专业对口，最直接
C++ 现代化 + 算法 5h 25% 跨所有方向，面试必问
英语 3h 15% 考研/外企/读文档都需要
信息源跟踪 2h 10% 知道行业在发生什么
休息/社交 2h 10% 别把自己榨干，这是四年的长跑

注意最后一行。 我见过太多人两个月废寝忘食然后倦怠退场。

持续性比强度重要得多。 每天 2 小时 × 300 天 = 600 小时，胜过一周突击 40 小时然后停摆三个月。

具体的四件事

① 硬件：买一块 STM32 开发板，动手

这是本学期最高 ROI 的投入。

项目 内容
买什么 STM32F103C8T6 最小系统板（淘宝十几块）或 F407（贵一点但资料多）
学什么 跟着江科大自化协的 STM32 视频（一整套，几十小时）
学到什么算过关 能独立用 HAL 库点亮一个 LED、读温湿度传感器（DHT22）、通过串口和电脑通信
额外建议 去问自动化学院老师能不能进实验室，有实验室经历在简历上是硬加分

为什么必须动手：

嵌入式是"软硬件两手抓"的行业，看视频学不会。你必须经历：

  • 程序烧不进去
  • 传感器读数是乱的
  • 时序对不上
  • 硬件坏了查半天

这种痛才是真正的学习。

配套要补的理论（同步看，不要等）：

  • 《数字电子技术基础》/《模拟电子技术基础》（你现在正在学的课，务必学扎实）
  • 《微机原理与接口技术》（如果有）
  • 单片机原理、时序分析

② C++：从"能用"到"懂原理"

你现在的 C++ 水平是"有一定基础"。这是好消息，比完全零基础快很多。

本学期要补的：

内容 为什么重要
指针 / 内存模型 嵌入式面试必问，也是理解 C 的基础
RAII 和智能指针 资源管理在嵌入式里极其重要（句柄、文件、内存都要管）
STL 容器 至少 vector、map、queue、array
现代 C++ 特性（C++11 之后） auto、lambda、move、智能指针、范围 for

怎么学： 不用买书。B站上有大量高质量的现代 C++ 教程，跟着敲一遍，再自己写小项目。

具体练手项目（正好用上你之前学的）：

把 GLFW 的 hello window 用 C++ 重新组织一遍 —— 封一个 Window 类，用 RAII 管理 GLFW 的初始化和销毁：

这个小练习能同时练到：封装、构造析构、拷贝禁用、RAII、常量正确性。 比你抄十遍教程有用。

③ 英语：别因为高考结束就放下

这是最容易被忽视、但回报极高的投资。

原因很实在：

  • 嵌入式领域的技术文档全是英文 —— 芯片手册、RTOS 官方文档、寄存器说明
  • 外企和合资企业要求英语（宝马、华为国际、汇丰、博世等）
  • 考研需要（哪怕你可能不考）
  • CSDN / 博客园的技术文章质量差一大截，想深入必须看英文原版
  • 官方文档是最好的学习材料 —— ST 的参考手册、FreeRTOS 官方文档

具体做法：

  • 每天 30 分钟，看英文技术文档
  • 首选材料：STM32F1xx Reference Manual（芯片手册）、FreeRTOS 官方文档、GLFW 官方文档
  • 不用刻意背单词，但要能看懂技术英语（术语重复率高，熟了就会）
  • 遇到生词就查，积累技术词汇

这招还有个副作用：你现在的 GLFW 官方文档就是英文的，读它就是免费的英语学习材料。

④ 跟踪信息源：知道行业在发生什么

很多学生到大三还对行业一无所知，这是最大的信息差。

建议关注：

类型 具体推荐
招聘平台 BOSS直聘、实习僧（现在就可以去刷）
行业新闻 电子发烧友、芯智讯、EEWorld
开源社区 RT-Thread、Zephyr、ESP-IDF 社区（看别人在做什么）
视频/图文 B站、小红书搜"嵌入式学习路线"，过来人会分享踩坑经验
官方文档 直接读 ST、FreeRTOS、ESP-IDF 的官方文档

具体动作（本周就做）：

打开 BOSS直聘 / 实习僧，搜索"嵌入式"，翻 20-50 个岗位的 JD，把出现频率最高的技能词抄下来。

这就是你的学习清单，比任何规划文章都准。

为什么这件事优先级这么高： 因为它成本极低（1 小时）但信息价值极高。它能告诉你：

  • 现在的市场到底要什么
  • 哪些技能是"必须"哪些是"加分"
  • 哪些岗位是给应届生的，哪些是给有经验的
  • 薪资区间的真实分布（不是招聘软件上的虚标）

本学期验收标准（2027年1月前）

到期末时，你应该是这样：

  • [ ] STM32 能独立完成：点亮 LED + 读 DHT22 + 串口通信 + 一个 PWM 控制
  • [ ] 有一个用 RAII 封装的小项目（可以是 GLFW 那个）
  • [ ] 刷了 100 道 LeetCode Easy
  • [ ] 读完了至少一份英文芯片手册的章节
  • [ ] 整理出了一份 50 个岗位的技能词清单
  • [ ] GPA 保持在专业前 30%（为了后面的选择权）

大三上（2027 秋）—— 深入 + 决策（最重要的学期）

这是决定你未来方向的关键学期。 因为要决定考研还是就业。

任务 说明
决定考研还是就业 必须在期末前想清楚，否则大三下无法准备

第二个项目 有一定难度，能体现你选的赛道

如果考研 3-10 月是强化期，别错过

学业 保持成绩（保研/评优需要）

关于考研的判断： 见第七节，单独展开。

大三下（2028 春）—— 实习 + 秋招

这是决定你最终 offer 质量的月份。

任务 优先级 说明
找实习 🔴 最高 目标：2 段，累计 3-4 个月
秋招准备 🔴 最高 简历 + 刷题 + 八股文
简历打磨 🟠 高 让有经验的人帮你看
刷题 🟠 高 编程题 + 嵌入式专项
毕设选题 🟡 中 越早越好，别拖到大四

为什么实习这么重要：

  • 嵌入式行业极度看重实习经历，因为上手成本高，公司不想招"需要从头培养"的人
  • 有实习经历的应届生和没实习的，简历通过率差几倍
  • 广工在广州，深圳实习资源丰富，学校又有 50+ 就业基地
  • 大三下没实习，大四秋招只能和有实习的人竞争，你会后悔

实习方向选择： 尽量去能做内核/驱动/系统层的岗位，不要去那种只做应用层调用库的公司。实习质量 > 实习数量。

大四上（2028 秋）—— 秋招决战

时间 动作
8-9 月 简历定稿、开始海投
9-11 月 秋招黄金期，全力面试
11-12 月 收 offer、比较决策
12 月 兜底（考研/春招准备）

秋招是唯一的黄金窗口。 错过这三个月，就要等明年春招，难度完全不同。

秋招策略：

  • 广撒网 —— 前 10 份不用太在意，先试试水
  • 后精准 —— 根据面试反馈调整，目标公司
  • 时间分配 —— 别把鸡蛋放在一个篮子，同时投多家

大四下（2029 春）—— 收尾

毕设收尾、论文、毕业手续、入职准备。

如果秋招没拿到满意 offer：

  • 1-3 月：春招（难度高于秋招，但要继续投）
  • 同时准备考研二战（如果要考）
  • 考虑先就业再择机

六、三个项目设计

原则：项目要能塞进简历的一行，并且能口述 3 分钟。

核心要求：项目要有"你自己的思考"痕迹，不能是教程照抄。

项目一：智能温湿度监测系统（大二下做）

技术栈：STM32F103 + DHT22 + OLED + WiFi模块 + MQTT + 云端

功能清单：

  • [ ] 实时采集温湿度
  • [ ] OLED 本地显示
  • [ ] WiFi 上报云端（OneNET / 阿里云 IoT 选一个）
  • [ ] 手机或网页查看数据
  • [ ] 亮点：数据异常报警（温度超阈值推送到手机）

涵盖关键词：STM32 / I2C / SPI / UART / MQTT / WiFi / 嵌入式 / 传感器

为什么这个项目好：

  • 覆盖的关键词和招聘要求几乎一一对应
  • 有"云端"部分，能体现完整系统思维
  • 能讲出很多"遇到什么问题、怎么解决"的细节

升级方向（让它不水）：

  • 用 FreeRTOS 而不是裸机（多任务：采集/显示/通信）
  • 自己画 PCB（如果你学了嘉立创EDA）
  • 加数据存储（SD卡 / Flash 掉电保存历史曲线）
  • 加离线告警（断网时也能推送）

项目二：PID 控制智能小车（大三上做）

技术栈：STM32F407 + 编码器 + 电机驱动 + PID 算法 + FreeRTOS + 蓝牙

功能清单：

  • [ ] 编码器闭环测速
  • [ ] PID 算法控制 PWM 输出
  • [ ] 蓝牙遥控 + 路径循迹
  • [ ] 用 FreeRTOS 多任务：控制任务、传感器任务、通信任务
  • [ ] OLED 显示 PID 参数（能现场调参）

涵盖关键词：PID / FreeRTOS / 闭环控制 / 多任务 / 定时器 / 编码器

为什么重要：

这个项目证明你懂控制逻辑和实时系统，不只是"调库"。嵌入式工程师的核心竞争力就是这个。

面试怎么讲：

  • 讲 PID 三个参数怎么调（Kp/Ki/Kd 的作用）
  • 讲超调、震荡怎么解决
  • 讲多任务优先级怎么设计
  • 讲遇到的实际问题（比如编码器测速抖动）

项目三：嵌入式 Linux 小系统（大三上/下做）

技术栈：Linux 开发板（正点原子/野火 ARM 板）+ Linux 驱动 + Qt/图形界面

功能清单（选做）：

  • [ ] 交叉编译 ARM 程序并运行
  • [ ] 写一个字符设备驱动
  • [ ] 交叉编译 Qt 程序做界面
  • [ ] 或者：把 STM32 智能小车升级成 WiFi 控制 + 网页界面

涵盖关键词：Linux 驱动 / 交叉编译 / ARM / 设备树 / Qt

为什么这个项目是分水岭：

Linux 驱动是应届起薪最高的方向（18-25K）。 虽然学习曲线陡，但一旦跨过去，薪资和天花板都不一样。

如果你决定考研，这个项目可以不着急；如果你决定就业，强烈建议做。

备选项目（如果时间有余）

项目 技术栈 涵盖方向
工业数据采集网关 Modbus 主站 + TCP 转 MQTT + 边缘存储 物联网网关（你专业最对口）
简易相机标定与检测工具 OpenCV + 串口通信 + 上位机界面 工业视觉（物联网+图形交叉）

这个话题绕不过去，我给一个诚实的分析。

隐性成本常被忽略：

很多人只看"读研三年"这个时间成本，忽略了：

  • 收入损失：三年不工作，按应届 6-8K 算，损失 20-30 万
  • 机会成本：三年本来能积累 3 年工作经验和收入
  • 压力：考研报考人数从 2017 年 228 万涨到 2024 年 438 万，竞争越来越激烈

反过来，本科就业也有隐性成本：技术天花板可能更低，跳槽议价能力更弱。

这个决定没有绝对对错，取决于你想要什么生活。

广工的现实

自动化学院有推免资格（保研），而且专业排名靠前。

具体建议：

  • 大二下结束时评估一次 GPA
  • 如果能进专业前 20%：开始认真准备（该做项目做项目，该刷题刷题，该打竞赛打竞赛）
  • 如果进不了前 20%：把重心完全放在项目和实习上，考研只当备选

推免的性价比极高 —— 不用参加竞争激烈的考研复试本校录取率极高。

九、简历怎么写

❌ 不要这样写

熟练使用 GLFW 进行 OpenGL 图形开发
熟悉 C++，了解 Linux

问题分析：

  • "熟练使用 XXX" 这种句式没有信息量，谁都能说
  • 只写"会用什么"，不写"解决了什么问题"
  • 换库就归零 —— 招聘方看重的是能力，不是你用过什么工具

✅ 应该这样写

嵌入式项目：

基于 STM32F407 + FreeRTOS 实现多任务温湿度监测系统，通过 MQTT 上报至云端；使用 CMake 管理工程，Git 版本控制；在 Linux 下用 GDB 定位并修复多任务竞态问题

C++ 项目：

独立完成基于 C++/OpenGL 的三维渲染器，实现相机控制、光照模型与纹理映射模块；使用 CMake 管理构建流程、GDB 调试定位内存问题

区别在哪：

❌ 弱写法 ✅ 强写法
熟练使用 GLFW 实现相机控制、光照模型
会用 CMake 使用 CMake 管理构建流程
了解 GDB 用 GDB 定位并修复竞态问题
做了温湿度监测 实现多任务 + MQTT 上报 + 修复竞态

后者体现的是"我解决了什么问题"，前者只是"我用过什么工具"。

简历结构建议

项目经历要放最前面，对本科生来说项目比 GPA 更能证明能力。

量化你的项目

尽量用数字说话：

❌ 弱 ✅ 强
实现了数据上报 实现了 1s 一次的数据上报，通过 MQTT 协议延迟低于 200ms
做了温湿度采集 采集误差 ±0.5℃，通过卡尔曼滤波优化了 DHT22 的抖动
做了小车控制 PID 控制，闭环响应时间 <100ms，无明显超调

十、面试会问什么

嵌入式岗位常见问题

C/C++ 基础（必问）

  • 指针和数组的区别
  • 栈和堆的区别，内存分配的生命周期
  • 野指针、空指针段错误
  • volatile 的作用
  • 内存对齐
  • 什么是字节序（大小端），怎么判断
  • 静态变量、全局变量的初始化时机
  • 编译过程（这就用到你之前学的！编译/链接/预处理的区别）

硬件/协议

  • SPI 和 I2C 的区别
  • UART 的波特率计算
  • 什么是中断，中断的触发条件
  • 看门狗的作用
  • 硬件上电复位流程
  • CAN 总线的仲裁机制

RTOS

  • 任务的状态和调度
  • 优先级反转是什么，怎么解决（优先级继承）
  • 信号量、互斥锁、队列的区别
  • 中断和任务的区别
  • RTOS 的实时性体现在哪

Linux

  • 进程和线程的区别
  • 虚拟内存是什么
  • 文件描述符
  • 怎么编译一个 C 程序（直接考你的工具链能力）
  • 交叉编译是什么，为什么要交叉编译

  • 为什么要用这个方案，有别的选择吗
  • 如果让你重做，会怎么改进

  • 什么是 VAO/VBO，为什么需要
  • 着色器怎么写，怎么调试
  • 什么是双缓冲，为什么需要
  • 深度测试是干什么的
  • 抗锯齿的原理

十一、八个最容易踩的坑

坑 1：学了一堆技术，做不出项目

嵌入式是"实践至上"的学科。你看 100 小时视频，不如花 20 小时调一个传感器 bug。

✅ 验收标准：每学完一块，必须有能跑起来的代码输出。

❌ 典型表现：跟着视频敲了 30 小时代码，一停下来就啥也不会。

坑 2：只学技术，不了解行业

你可能花三个月学完 RTOS，却不知道嵌入式工程师的薪资分层是 6K 到 25K 起步。信息差是最贵的成本。

✅ 验收标准：能清楚说出"我想做车载电子，因为 X 原因，薪资大概 Y"。

坑 3：项目太水，简历没东西写

"基于 STM32 的温湿度监测" 谁都能写，面试官一看就知道是教程照抄。

✅ 升级方法：在教程基础上加一个自己的改进，哪怕很小：

  • 加了数据异常报警
  • 用了 FreeRTOS 而不是裸机
  • 自己画了 PCB
  • 做了手机端界面
  • 做了数据持久化

有"自己的思考"痕迹的项目才值钱。

坑 4：大三下才开始找实习

实习是找实习，不是实习经历。 大三下没实习，大四秋招就只能和有实习的人竞争。你会后悔。

✅ 什么时候开始：大三上就该关注实习信息，大三下开学立刻投。

坑 5：为了"找工作"而考一堆无关证书

CFA、ACCA 对嵌入式工程师完全无用。真正有用的是 CET-4/6、HCIA-IoT、软考初级、驾照。

✅ 原则：证书只考"目标岗位 JD 里明确要求"的。

坑 6：把 GPA 排第一，但项目做得少

成绩固然重要，但嵌入式行业看的是能不能干活。成绩中上 + 项目牛，比成绩第一 + 什么都不会强得多。

✅ 但不要放弃成绩：为了保研/考研/评优/国企，绩点还是要保持。均衡发展，不是二选一。

坑 7：追求"学完"再开始

"等我学完 C 语言就去做项目"、"等我学完 RTOS 就做小车" —— 这是最常见的拖延陷阱。

✅ 正确做法：学 20% 就做 80% 的事。

  • 学了前 20 小时 C 语言 → 立刻做一个小项目（LED 点亮）
  • 学了前 3 天 STM32 → 立刻做一个温湿度采集
  • 学了前 1 周 FreeRTOS → 立刻做一个双任务 LED 闪烁

学不全没关系，用起来再补。

坑 8：一个人闷头做，没人指导

嵌入式领域有很多"看起来很美但实际是弯路"的做法（比如某些特定的库、某些架构）。多和学长、老师、实习生交流，能省下几个月。

✅ 具体做法：

  • 加几个嵌入式学习群/社区（RT-Thread、ESP-IDF 官方群）
  • 关注 2-3 个高质量的技术博主
  • 大三下找到实习后，多问实习生师兄
  • 广工自动化学院有老师答疑渠道，用起来

十二、关键节点与决策检查点

大二下期末（约 2027 年 6-7 月）

第一个决策点：考研还是就业？

评估三个问题：

  1. 我的 GPA 在专业前 20% 吗？
  2. 我对图形/算法这类需要读研的方向有兴趣吗？
  3. 我的家庭情况支持我读研吗？

决策影响接下来 12 个月的所有安排，所以必须定。

大三上期末（约 2027 年 12-1 月）

第二个决策点：实习拿到了吗？方向定了吗？

  • 如果定了就业 → 全力找实习
  • 如果定了考研 → 3-10 月是数学强化期，不能被实习打断
  • 如果两者都想要（很危险）→ 必须果断选一个

大三下初（约 2028 年 3 月）

第三个决策点：秋招怎么投？

  • 简历定稿，找人帮忙审
  • 明确目标公司清单
  • 开始海投，先试水

大四上（2028 年 8-11 月）

第四个决策点：Offer 比较

判断维度（按重要性）：

  1. 赛道（是车载电子还是传统单片机？）
  2. 团队（做内核/驱动还是应用层？）
  3. 城市（深圳/广州/杭州？）
  4. 薪资
  5. 加班强度

前三条比薪资重要。 起薪差 3K 但赛道差 3 倍的情况很常见。

十三、反焦虑：几个重要提醒

1. 你不需要和任何人比较

同学里有人在大二就拿了腾讯的实习offer，那是别人的路径。你要走自己的路。

嵌入式行业不看"进度快慢"，看你能不能干活。 大三下有 2 段实习 + 2 个项目，胜过"大一就开始刷题"的人。

2. 这是长跑，不是冲刺

四年，1600 多天。每天 2 小时 × 1600 天 = 3200 小时，足够从零基础到能胜任嵌入式工作。

但如果"每天 4 小时 × 60 天然后停摆"，最终什么都不剩。

可持续性 > 强度。

3. 允许自己学得慢

嵌入式是软硬件结合的领域，看不懂硬件电路、听不懂操作系统原理，都是正常的。这个领域本来就是边做边学。

不要因为"看不懂"就怀疑自己不适合。 所有人都看不懂，看懂是靠重复。

4. 焦虑的根源是"想太多、做太少"

如果做完这些事还焦虑：

  1. 写下来（不要只在脑子里想）
  2. 拆成可执行的小任务（今天具体做什么）
  3. 做掉第一个任务（哪怕只是"打开 BOSS直聘搜嵌入式"）

行动本身就是最好的解焦虑药。

5. 你的专业不差，别有"物联网是夕阳"的错觉

物联网是国家战略方向，人才缺口 170 万。广工这个专业排名全国前 7。你在一个上升的领域，不需要转行。

6. 图形学那件事，放弃得对

"一时兴起"很正常。沉没成本只有 200 行代码和几个小时。

但你从那件事里学到的东西不会消失：

  • 编译链接的过程
  • CMake / 工具链配置
  • GDB 调试
  • 读英文文档

这些是真实的能力，会在 STM32 项目里复用。 不算白学。

十四、附录A：数据来源与说明

广工就业数据来源

  • 广工自动化学院就业工作官网（automation.gdut.edu.cn）
  • 第三方就业数据平台统计（就业率 95%+、薪资曲线、地区分布）
  • 掌上高考平台专业介绍（物联网工程专业排名）

说明：不同数据源的就业率统计口径可能不同（是否包含考研、灵活就业），具体以学校官方发布为准。

嵌入式薪资数据来源

  • 多个招聘平台（BOSS直聘、实习僧、牛客网、国家大学生就业服务平台）
  • 行业分析文章（2026 年，多篇）
  • 公司招聘 JD 摘录（比亚迪、华为、腾讯、紫龙游戏等）

说明：薪资数据受城市、公司规模、岗位级别影响很大。表中的数字是区间参考，不是保证。具体以你实际投递的 JD 为准。

关键提醒

所有薪资数据都有时效性。 你毕业是 2028 年，届时行业情况会有变化。定期重新查一次招聘数据（每学期一次）：

  1. 去 BOSS直聘搜索你的目标岗位
  2. 看 20-50 个 JD
  3. 统计出现最多的技能词
  4. 关注薪资区间变化

这应该是你每学期必做的一件事。

最后的话

你现在大二上，起点是好的：

  • ✅ 广工物联网工程是优势专业（全国前 7）
  • ✅ 广东的嵌入式产业就在家门口（广州 63% + 深圳 13%）
  • ✅ 行业人才缺口 170 万，本科门槛友好
  • ✅ 你已经有一些 C++ 基础，还搞懂了编译工具链
  • ✅ 你已经在认真思考职业规划（很多人大四都没开始想）

你唯一要做的，就是从今天开始动手。

具体地、今天：

  1. 去淘宝下单一块 STM32F103C8T6 开发板（约 15 元）
  2. 打开 BOSS直聘，搜索"嵌入式"，翻 20 个岗位
  3. 把你现在学的 C++ 里，一个你不理解的概念搞明白

这三件事，加起来不到一小时。

四年后，你会感谢今天的自己。

笔记整理完毕。核心记忆点：

  • 主线：嵌入式 Linux 驱动 / 边缘 AI，起薪最高
  • 当下：STM32 + C++ 现代化 + 英语 + 刷岗位，四件事
  • 大二下：做完第一个项目（温湿度监测）
  • 大三上：决定考研 or 就业（关键节点）
  • 大三下：找实习（最高优先级）
  • 大四上：秋招决战（唯一黄金窗口）
